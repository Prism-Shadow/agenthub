# DeepSeek 尚未上线前预先登记 `deepseek-v4.1-flash`

- **Date:** 2026-09-09
- **Type:** feature
- **Scope:** `registry`
- **PR:** [#203](https://github.com/Prism-Shadow/agenthub/pull/203)

[English](2026-09-09-deepseek-v4.1-flash.md)

## 变更内容

- 在注册表中于 `deepseek-v4-flash` 之前新增 `deepseek-v4.1-flash`，使该系列最新一代排在前面。DeepSeek 宣布该模型将于 2026-09-10 之后发布，2026-09-09 尚未提供服务。
- 该 id 无需改动路由或客户端：`AutoLLMClient` 已将所有包含 `deepseek-v4` 的 client type 交给 `DeepSeekV4Client`，纯文本模型的拒绝名单（`^deepseek-v4-(flash|pro)(-\d{4})?$`，见[图片开关](2026-09-08-deepseek-image-gate.zh.md)）也已放行 `deepseek-v4.1-flash` 的图片转发。
- `skills/agenthub-python/reference/models.md` 与 `skills/agenthub-typescript/reference/models.md` 中 DeepSeek Official 的 id 列表新增该 id。
- 受环境变量控制的 `AVAILABLE_MODELS` E2E 列表未新增：DeepSeek 尚未提供服务的 id 会导致每次请求都失败。

## 注册表元数据

| 字段 | 取值 |
| --- | --- |
| `base_url` | `https://api.deepseek.com` |
| `client` | `deepseek-v4` |
| `input_modalities` | `Text`、`Image` —— 依据 DeepSeek 的公告为多模态 |
| `output_modalities` | `Text` |
| `context_window` | 1,000,000 —— 为假定值而非官方公布值：取自 `deepseek-v4-flash`，在官方模型页给出数值前沿用 |
| `pricing` | 每百万 token 输入 CNY 1.0、输出 4.0、缓存命中 0.02，即自 2026-09-10 起生效的 V4 Flash 系列空闲时段牌价；高峰时段（北京时间 9:00-12:00、14:00-18:00）为两倍 |
