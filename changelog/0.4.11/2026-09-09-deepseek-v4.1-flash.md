# `deepseek-v4.1-flash` pre-registered before DeepSeek serves it

- **Date:** 2026-09-09
- **Type:** feature
- **Scope:** `registry`
- **PR:** [#203](https://github.com/Prism-Shadow/agenthub/pull/203)

[中文版](2026-09-09-deepseek-v4.1-flash.zh.md)

## What changed

- `deepseek-v4.1-flash` was added to the registry above `deepseek-v4-flash`, so the newest
  generation of the series comes first. DeepSeek announced the model for release after
  2026-09-10 and did not serve it on 2026-09-09.
- The id needed no routing or client change: `AutoLLMClient` already sends every client type
  containing `deepseek-v4` to `DeepSeekV4Client`, and the text-only deny-list
  (`^deepseek-v4-(flash|pro)(-\d{4})?$`, see
  [the image gate](2026-09-08-deepseek-image-gate.md)) already lets `deepseek-v4.1-flash`
  forward its images.
- The DeepSeek Official id lists in `skills/agenthub-python/reference/models.md` and
  `skills/agenthub-typescript/reference/models.md` gained the id.
- The env-gated `AVAILABLE_MODELS` E2E lists did not: an id DeepSeek does not serve yet would
  fail every request.

## Registry metadata

| Field | Value |
| --- | --- |
| `base_url` | `https://api.deepseek.com` |
| `client` | `deepseek-v4` |
| `input_modalities` | `Text`, `Image` — multimodal per DeepSeek's announcement |
| `output_modalities` | `Text` |
| `context_window` | 1,000,000 — assumed, not published: the value is `deepseek-v4-flash`'s, and stands until the official model page lists one |
| `pricing` | CNY 1.0 prompt / 4.0 output / 0.02 cache-hit per million tokens, the V4 Flash series off-peak list price effective 2026-09-10; peak hours (Beijing 9:00-12:00, 14:00-18:00) are double |
