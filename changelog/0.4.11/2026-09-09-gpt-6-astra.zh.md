# 支持 GPT-6 Astra

- **Date:** 2026-09-09
- **Type:** feature
- **Scope:** `gpt6`, `registry`, `auto_client`, `openai_responses`
- **PR:** [#204](https://github.com/Prism-Shadow/agenthub/pull/204)

[English](2026-09-09-gpt-6-astra.md)

## 变更内容

- AgentHub 在官方 OpenAI API 上支持 `gpt-6-astra`，在 OpenRouter 上支持 `openai/gpt-6-astra`：
  输入支持文本与图像，输出为文本，上下文窗口 1,050,000 token，输入上限 922,000 token，
  输出上限 128,000 token。
- 其 wire 契约与 GPT-5.6 代完全一致，因此共享的客户端目录照例按最新一代重命名：两种语言中
  `gpt5_6/` 改为 `gpt6/`，`GPT5_6Client` 改为 `GPT6Client`。官方 OpenAI 注册表中原先以
  `gpt-5.6` 为 client 的条目一律改为 `gpt-6`。
- `auto_client.py` / `autoClient.ts` 在 `gpt-5.6`、`gpt-5.5`、`gpt-5.4` 之外一并路由 `gpt-6`，
  不支持的 client type 提示信息中也列出了它。`gpt-5.6`、`gpt-5.5` 与 `gpt-5.4` 仍是可用的
  `client_type` 写法，并会路由到重命名后的客户端。
- 模型 id 含 `gpt-6` 时，`ThinkingLevel.NONE` 收敛为 `low`。该代对 `none` 与 `minimal` 均返回
  HTTP 400：`Unsupported value: 'none' is not supported with the 'gpt-6-astra' model.
  Supported values are: 'low', 'medium', 'high', 'xhigh', and 'max'.`；其他模型 id 仍保持
  `none`。通用的 `openai_responses` 客户端适用同一规则，因为 `openai/gpt-6-astra` 的 OpenRouter
  条目正是经由它路由。
- reasoning item 的 `encrypted_content` 只从 `response.output_item.done` 采集。streaming-events
  参考文档对 `response.output_item.added` 的说明是："The output item that was added. For
  reasoning items, `encrypted_content` may be incomplete while the item is in progress. Use the
  reasoning item from the corresponding `response.output_item.done` event when passing it as
  input to a subsequent request."。客户端注释现引用该句，两种语言的 reasoning fidelity 测试套件
  也新增了一张 Responses 协议用例表：在 added 事件上下发被截断的 `encrypted_content`，断言只有
  完成事件的取值进入回放的 reasoning item。
- `llmsdk_docs/gpt6/` 收录模型页、GPT-6 模型指南、推理指南与提示缓存指南；`POST /v1/responses`
  参考快照一并刷新，`llmsdk_docs/openai_responses/docs/openai-responses-streaming-events.md`
  新增 streaming-events 参考文档的标注摘录，覆盖 output item 生命周期事件、`response.reasoning_*`
  事件、终止事件与 usage 对象。

## 注册表元数据

| 字段 | `gpt-6-astra` | `openai/gpt-6-astra` |
| --- | --- | --- |
| `base_url` | `https://api.openai.com/v1` | `https://openrouter.ai/api/v1` |
| `client` | `gpt-6` | `openai-responses` |
| 输入 / 输出模态 | Text、Image / Text | Text、Image / Text |
| `context_window` | 1,050,000 | 1,050,000 |
| `pricing` | `usd(12.5, 50.0, 1.0)` | `usd(12.5, 50.0, 1.0)` |

OpenAI 每百万 token 的牌价为：缓存输入 $1、未缓存输入 $10、缓存写入 $12.5、输出 $50；输入超过
272K token 时输入与缓存费率翻倍、输出费率为 1.5 倍，Batch 与 Flex 为标准价的 50%，Fast 模式为
2 倍。prompt 档位采用缓存写入费率，因为 AgentHub 的用量档位并不区分缓存写入的输入与普通输入。
2026-09-09 查询 OpenRouter models API，其默认 OpenAI 端点报出的四档费率与上述一致，且无折扣。
